// PROJECT SHOWCASE

白银之城 // SILVER PALACE

> 开放世界关卡设计 // OPEN WORLD LEVEL DESIGN

白银之城是一款开放世界都市题材项目的关卡设计作品。作为关卡策划与载具功能负责人，深度参与了城区空间规划、飞行载具系统设计、副本体验构建等核心内容，探索复杂都市空间中玩家体验的最优解。

// PROJECT TYPE

开放世界都市关卡设计

项目类型为开放世界都市关卡设计，涵盖POI设计、区域资源规划、氛围内容布设、副本关卡体验（Boss战/潜行刺杀/跑酷等）以及载具系统的整体定标与商业化规划。

// CORE CHALLENGES

核心挑战

1. 飞行载具与复杂建筑碰撞结构的适配
2. 城区布局与探索体验的节奏控制

在保留真实建筑空间探索感的同时，确保飞行状态下的流畅体验；通过空间设计引导玩家自然地在天空与地面之间流动。

NOTE.01

叙事副本中往往需要涵盖多种玩法来调整探索结构、调节探索节奏，潜行与刺杀属于狭窄区域中体验较为丰富的小型战斗玩法选择，其也能更好的使玩家沉浸在紧张的环境氛围当中。而如果在装饰复杂的环境中，玩家如何发现巡逻怪？如何选择刺杀、躲避路径？如何判断何时应该潜行，都是非常重要的设计课题。

NOTE.07

随着后续资产堆积的方式、通道平台等结构的尺寸，能够直观的给玩家带来体验上的变化，作为关卡策划，同时也需要对场景想传达出来的氛围有所把握，能够在场景后续迭代中准确地向美术、音效部门提出符合氛围的设计需求。

NOTE.08

对于开放世界的载具而言，不但作为被高频率使用的交通工具，其也会承载着玩法、商业化的期待，如何做好开放世界环境下的竞技赛事是当下各开放世界游戏的课题。

NOTE.09

赛马、赛车这种以载具为主的玩法不单要考虑操控手感、逻辑，同时也需要考虑那些真正能让玩家感受到刺激、兴奋、紧张的"赛事感"！ 让玩家感受到NPC不断冲击领先位置，通过NPC告知玩家赛道的解题思路，让NPC真正能够"陪伴"玩家跑完紧张刺激的全过程等等表现，都标志着NPC是赛事玩法中不可或缺的部分。

赛道的指引性对于复杂大世界环境下的赛事玩法尤为重要，除却道具、路牌这些明显的指示物，地面铺装、连续灯带等等融入在大世界环境中的铺设也能起到很好的作用。当然，如何处理玩法拉起后的性能表现是大型开放世界游戏共有的课题。
